# 💼 My Portfolio — Tailwind CSS &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; [![View it live](https://img.shields.io/badge/Live-Demo-blue)](https://kanha1235.github.io/my-portfolio/)

A modern, responsive single-page portfolio website built with **Tailwind CSS** and **vanilla JavaScript**, designed to showcase my projects, skills, and contact information.

---

## 🚀 Features

- **Sticky Header:** A glass-blur header that remains visible on scroll.
- **Responsive Navigation:** Desktop menu + hamburger for mobile screens.
- **Hero Section:** Full-screen intro with background image, tagline, and CTA button.
- **About Me:** Profile photo, short bio, and key skills using Tailwind flex & grid utilities.
- **Projects Section:** Responsive grid with hover animations, live/code links, and custom screenshots.
- **Contact Form:** Functional form layout (static for now) with email, LinkedIn, GitHub, Codeforces, and LeetCode links.
- **Footer:** Clean copyright footer with placeholder policy links.
- **Lucide Icons:** Lightweight open-source icon system for consistent vector icons.
- **Tailwind Utilities:** Uses custom colors, spacing, transitions, and shadows.

---

## 🛠️ Tech Stack

| Layer | Tools Used |
|-------|-------------|
| **Frontend** | HTML5, Tailwind CSS, Vanilla JavaScript |
| **Icons** | [Lucide](https://lucide.dev/) |
| **Build Tool** | Tailwind CLI (`npx tailwindcss -i ./input.css -o ./output.css --watch`) |
| **Deployment** | GitHub Pages / Netlify |

## ⚙️ Getting Started

### 1️⃣ Clone the repo
```bash
git clone https://github.com/Kanha1235/my-portfolio.git
cd my-portfolio

2️⃣ Install dependencies
npm install

3️⃣ Start Tailwind CLI (watch mode)
npx tailwindcss -i ./input.css -o ./output.css --watch

4️⃣ Open in browser

Just open index.html in your browser or use a local Live Server extension in VS Code.

🎨 Customization

You can change:

Background image in the hero section (<section id="home">)

Project screenshots inside /src

Colors and spacing in tailwind.config.js

Add new skills or projects in the corresponding sections of index.html

📱 Responsiveness

Mobile-first design using Tailwind’s responsive classes (sm:, md:, lg:).

Navbar automatically collapses into hamburger menu below md breakpoint.

All sections (hero, about, projects, contact) are fluid and adapt to any device width.

🧾 GitHub Pages Deployment

If you want to deploy your portfolio using GitHub Pages, follow these steps:

1️⃣ Create a GitHub repository

Name it my-portfolio (or any name you prefer).

2️⃣ Push your project
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/<your-username>/my-portfolio.git
git push -u origin main

3️⃣ Enable GitHub Pages

Go to Settings → Pages.

Under Source, select main branch and set the root folder / (or /docs if you place your HTML there).

Click Save.
Your site will be live at:

https://<your-username>.github.io/my-portfolio/
